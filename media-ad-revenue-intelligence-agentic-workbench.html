      README — How to use this workbench
      Agentic Revenue Intelligence Workbench
      A demonstration of how a coordinated team of AI agents can remove pre-call prep and bad-data drag so sales reps spend their time selling. It is one connected workflow spanning UC-01 AI SDR / Outbound Sales, UC-02 Strategic Account Intelligence, and UC-03 CRM / Sales Engagement Workflow, running on a shared data foundation. 27 purpose-built AI agents support the three use-cases — 26 run in the automated cross-functional pipeline, plus Account Plan Generator which runs on-demand within UC-02. All companies, advertisers, publications, systems, vendors and figures shown are fictional sample data.
      ≡ Quick start
      1 · Take the guided tour
      Click ▶ Start Demo in the top bar. The tour walks through each screen automatically. Click anywhere to pause, press Esc to exit.
      2 · Explore the agents
      Open AI Agents for the full directory, then Pipeline and press Run Full Pipeline to watch the agents activate across four waves.
      3 · Generate and refine outputs
      On any use-case screen, use the Generate buttons to draft outreach, account plans and briefs. Type an instruction in the Refine this output box (for example "make it a 20 minute call" or "shorter") and press Revise.
      4 · Approve before anything is sent
      Actions such as sending outreach or scheduling a call sit behind a human approval step. Nothing leaves the workbench without a click.
      Running it locally or on the web
      Open the file in any modern browser with internet access (charts and PDF export load from public libraries). AI generation is live when the page runs inside Claude; when opened as a standalone file it uses built-in sample outputs, and Revise supports simple edits such as call length, timing, tone, shorter, add a P.S., or a new sign-off.
      ≡ The 27-agent architecture, scoped to 3 use-cases
      Data Foundation — supports all 3 use-cases (6 agents)
      Data Ingestion → Deduplication → Quality & Compliance → Anomaly Detection → Record Composer → Stakeholder Notification. Runs sequentially. Produces the unified advertiser data layer every use-case reads from.
      UC-01: AI SDR / Outbound Sales (8 agents)
      Vertical & Territory Planner, Prospect Discovery, Enrichment Router, Lead Qualification, CRM Hygiene / Gate, Whitespace & Expansion Signal, Outreach Personalisation, Sequence Orchestrator. Runs the six-stage pipeline: Plan → Find → Map → Gate → Engage → Recommend.
      UC-02: Strategic Account Intelligence (9 agents)
      Account Intelligence, Account Plan Generator, Competitive Signal, Renewal Risk, Retention Strategy, Success Report, Churn Prediction, Upsell Propensity, ARR Forecast. Health scoring, renewal risk, retention playbooks, and revenue outlook unified in one screen.
      UC-03: CRM / Sales Engagement Workflow (4 agents)
      CRM Enrichment, Activity Logging (shared with UC-01), Pipeline Health Monitor, Workflow Automation. Keeps CRM, sales engagement, and ad-serving in sync with the same hygiene layer UC-01 uses at the gate.
      ≡ What each screen does

      ⚙ UC-03: CRM / Sales Engagement Workflow
