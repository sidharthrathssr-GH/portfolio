# AI Project Portfolio

Interactive demos of AI and analytics solutions, viewable in the browser. All data in the demos is fictional sample data.

| Project | Domain | What it shows |
|---|---|---|
| [Ad Revenue Intelligence Workbench](media-ad-revenue-intelligence-agentic-workbench/) | Media & Advertising, Agentic AI | 27 coordinated AI agents for outbound sales, strategic account intelligence and CRM workflow automation, with human approval before anything is sent |

## How the repo is organised

- `index.html` is the landing page that lists the projects.
- Each project lives in its own folder named after what it does, with its demo in `index.html` inside that folder.
- To add a project: create a new folder, put its `index.html` inside, then copy a card block in the root `index.html` and point it at the new folder.
